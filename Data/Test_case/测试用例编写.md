## Excel预期结果列写法规则

**只看一列：`预期结果`**

### 6种写法，分号分隔

| 写法 | Excel里怎么填 | 例子 |
|------|-------------|------|
| 等值 | `$.字段=值` | `$.code=200` |
| 不等 | `$.字段!=值` | `$.code!=500` |
| 非空 | `not_empty=$.字段` | `not_empty=$.data.name` |
| 包含 | `contains=$.字段,值` | `contains=$.message,成功` |
| 类型 | `type=$.字段,类型名` | `type=$.code,int` |
| 长度 | `length=$.字段,比较符数字` | `length=$.data.list,>=1` |

### 字段路径用jsonpath写法

| 响应结构 | 怎么写 |
|---------|--------|
| `{"code":200}` | `$.code` |
| `{"data":{"name":"万和"}}` | `$.data.name` |
| `{"data":{"user":{"id":10086}}}` | `$.data.user.id` |
| `{"data":{"list":[{"name":"万和"}]}}` | `$.data.list[0].name` |

### 类型名对照

`int` `str` `list` `dict` `float` `bool`

### 长度比较符

`>=1` `<=5` `>0` `<10` `==0` `=3`

### 组合写法（分号隔开）

```
$.code=200;$.message=操作成功;not_empty=$.data.name;contains=$.message,成功;type=$.code,int;length=$.data.list,>=1
```

想断言几条就写几条，分号隔开就行。
