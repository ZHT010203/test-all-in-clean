# 最新版本

## 一、conftest层（基础设施层）

位置：`api_test_framework/conftest.py`
职责：登录拿token、实例化 HTTPClient / DBClient / ExcelReader，通过 fixture 注入到测试函数。
**测试文件不用自己 new 这些类，直接当入参用。**

### 提供的 fixture

| fixture名 | 作用域 | 说明 |
|-----------|--------|------|
| `admin_login` | session | 拿token，返回 `{"token":"xxx","headers":{...}}` |
| `admin_client` | session | HTTPClient实例，已注入token，直接发请求 |
| `db_client` | session | DBClient实例，查数据库用 |
| `read_excel` | function | 读Excel用例（用executor时不用这个） |

### 底层代码结构（conftest.py 核心）

```python
# 1. 登录拿token（session级，整个测试只登一次）
@pytest.fixture(scope="session")
def admin_login():
    resp = requests.post(ADMIN_BASE_URL + ADMIN_LOGIN, json={
        "username": ADMIN_USERNAME, "password": ADMIN_PASSWORD
    })
    token = resp.json()["data"]["token"]
    return {"token": token, "headers": {"Authorization": f"Bearer {token}"}}

# 2. HTTPClient注入token（session级，复用连接）
@pytest.fixture(scope="session")
def admin_client(admin_login):
    client = HTTPClient(
        base_url=ADMIN_BASE_URL,
        default_headers=admin_login["headers"],
        timeout=30, max_retries=3
    )
    yield client
    client.close()

# 3. 数据库客户端（session级）
@pytest.fixture(scope="session")
def db_client():
    client = DBClient(db_config=MYSQL_CONFIG, pool_size=5)
    yield client
    client.close()

# 4. 读Excel用例（function级）
@pytest.fixture
def read_excel():
    reader = ExcelReader()
    def _read(file_name, required_cols=None):
        return reader.read(os.path.join(TEST_CASE_DIR, file_name), required_cols)
    return _read
```


## 二、接口测试层（业务层）

位置：`api_test_framework/test_xxx.py`
职责：只管"测哪个接口"，依赖从 conftest 注入。

### 推荐写法（用executor，4行）

```python
from common.executor import ApiExecutor

def test_brand_delete(admin_client):
    ApiExecutor(admin_client).run("删除品牌.xlsx")
```

- 实例化的类：`ApiExecutor`（传入 conftest 的 `admin_client`）
- 调用的方法：`.run("Excel文件名")`
- 读Excel、发请求、断言、并发、异常兜底、回写——executor 全包

### 手动写法（不用executor，了解即可）

需要手动实例化和调用这几个类：

| 类 | 实例化 | 调用方法 |
|----|--------|---------|
| `ExcelReader` | `ExcelReader()` | `.read(file_path, required_cols)` |
| `HTTPClient` | conftest的`admin_client`（不用自己new） | `.post(url, json=...)` |
| `AssertEngine` | `AssertEngine(result)` | `.assert_result(预期结果, 测试点)` |
| `ConcurrentRunner` | `ConcurrentRunner(max_workers=5)` | `.run(tasks, func, timeout)` |
| `ResultWriter` | `ResultWriter()` | `.collect(...)` → `.write_back(file_name)` |

参考 `test_brand_create.py`（约60行）。能用 executor 就用 executor，4行顶60行。
