# 新版本

# HTTP请求类 (http_client.py - HTTPClient)
封装requests，统一请求头、超时、日志、状态码检查。

对应函数方法：
retry_on_network_error() - 失败重试装饰器（仅网络异常重试，业务异常不重试）
set_headers()            - 更新默认请求头
request()                - 统一请求方法（被下面的方法调用）
get() / post() / put() / delete() - 四种请求
close()                  - 关闭Session


# 数据库类 (db_client.py - DBClient)
封装pymysql，连接池、自动资源管理、统一异常。

对应函数方法：
fetchone()   - 查询单条（返回dict）
fetchall()   - 查询多条（返回list[dict]）
query()      - fetchall别名
execute()    - 执行SQL，返回影响行数
insert()     - 插入单条（传dict，自动生成SQL）
update()     - 更新（传dict + where条件）
delete()     - 删除（传where条件）
executemany()- 批量执行
close()      - 关闭连接池


# 断言类 (assertion.py - AssertEngine)
基于jsonpath_ng取值，用pytest.assert断言。实例化时传入接口返回字典。

对应函数方法：
assert_result()    - 核心方法，从Excel预期字符串解析断言，支持6种格式：
                     等值 $.code=200
                     不等 $.code!=500
                     非空 not_empty=$.data.name
                     包含 contains=$.message,成功
                     类型 type=$.code,int
                     长度 length=$.data.list,>=1
assert_not_empty() - 断言字段非空（None/空串/空列表/空字典都算空）
assert_contains()  - 断言字段包含某值
find_in_list()     - 在大列表中查找指定条件的数据，返回找到的dict（响应1000条找1条）


# 测试用例类 (excel_reader.py - ExcelReader)
读取Excel测试用例，按列名匹配（不依赖列顺序），清洗脏数据，返回list[dict]。

对应函数方法：
read(file_path, required_cols, sheet_name) - 读取Excel，返回list[dict]
  流程：校验文件→校验必填列→清洗空值→to_dict返回


# 回写测试用例类 (result_writer.py - ResultWriter)
收集每条用例结果，最后一次性回写到新Excel文件（不改原文件）。

对应函数方法：
collect(row, actual_result, status, error_msg) - 收集单条结果
  row: Excel行号（从2开始）
  status: "PASS" / "FAIL" / "ERROR"
write_back(file_name) - 回写到 Data/Test_report/原文件名_结果.xlsx


# 并发执行器 (runner.py - ConcurrentRunner)
用ThreadPoolExecutor并发跑用例，无锁设计（线程只返回结果元组，主线程串行collect）。

对应函数方法：
run(tasks, func, timeout=None) - 并发执行，返回结果列表（按row排序）
  tasks: 任务列表 [(i, case), ...]
  func:  处理单条用例的函数，返回 (row, actual, status, err)
  4个进阶能力：超时控制、异常兜底、结果统计、进度回调
