# 最新版本（含新增工具类）


## HTTP请求类 (http_client.py - HTTPClient)
封装requests，统一请求头、超时、日志、状态码检查、网络异常重试。
链路测试时支持 ${var} 占位符替换（传 context 参数）。

对应函数方法：
retry_on_network_error() - 失败重试装饰器（仅网络异常重试，业务异常不重试）
set_headers()            - 更新默认请求头
_merge_headers()         - 合并默认请求头和自定义请求头（内部）
_build_url()             - 拼接完整URL（内部）
_resolve_value()         - 传context时替换字符串里的${var}，否则原样返回（内部，新增）
request()                - 统一请求方法，新增 context 参数支撑链路测试
get() / post() / put() / delete() - 四种请求，均新增 context 参数
close()                  - 关闭Session


## 数据库类 (db_client.py - DBClient)
封装pymysql，连接池、自动资源管理、统一异常。

对应函数方法：
fetchone()   - 查询单条（返回dict）
fetchall()   - 查询多条（返回list[dict]）
query()      - fetchall别名
execute()    - 执行SQL，返回影响行数
insert()     - 插入单条（传dict，自动生成SQL）
update()     - 更新（传dict + where条件）
delete()     - 删除（传where条件）
executemany()- 批量执行
close()      - 关闭连接池


## 断言类 (assertion.py - AssertEngine)
基于jsonpath_ng取值，用pytest.assert断言。实例化时传入接口返回字典。
新增 db_client 可选参数，支持数据库断言。

对应函数方法：
assert_result()        - 核心方法，从Excel预期字符串解析断言，支持6种格式：
                         等值 $.code=200
                         不等 $.code!=500
                         非空 not_empty=$.data.name
                         包含 contains=$.message,成功
                         类型 type=$.code,int
                         长度 length=$.data.list,>=1
assert_not_empty()     - 断言字段非空
assert_contains()      - 断言字段包含某值
find_in_list()         - 在大列表中查找指定条件的数据，返回找到的dict
assert_db_record()     - 【新增】断言数据库存在指定记录并校验字段值
assert_db_not_exists() - 【新增】断言数据库不存在指定记录（删除/取消场景）


## 测试用例类 (excel_reader.py - ExcelReader)
读取Excel测试用例，按列名匹配，清洗脏数据，返回list[dict]。

对应函数方法：
read(file_path, required_cols, sheet_name) - 读取Excel，返回list[dict]
  流程：校验文件→校验必填列→清洗空值→to_dict返回


## 回写测试用例类 (result_writer.py - ResultWriter)
收集每条用例结果，最后一次性回写到新Excel文件（不改原文件）。

对应函数方法：
collect(row, actual_result, status, error_msg) - 收集单条结果
  row: Excel行号（从2开始）
  status: "PASS" / "FAIL" / "ERROR"
write_back(file_name) - 回写到 Data/Test_report/原文件名_结果.xlsx


## 并发执行器 (runner.py - ConcurrentRunner)
用ThreadPoolExecutor并发跑用例，无锁设计（线程只返回结果元组，主线程串行collect）。

对应函数方法：
run(tasks, func, timeout=None) - 并发执行，返回结果列表（按row排序）
  tasks: 任务列表 [(i, case), ...]
  func:  处理单条用例的函数，返回 (row, actual, status, err)
  4个进阶能力：超时控制、异常兜底、结果统计、进度回调


## 日志模块 (logger.py - setup_logger) 【新增】
统一配置root logger，RotatingFileHandler按大小切割日志，防撑爆磁盘。

对应函数方法：
setup_logger(level=logging.INFO) - 配置日志（文件10MB轮转保留5份 + 控制台输出）


## 测试上下文 (context.py - TestContext) 【新增】
多接口链路测试的变量传递核心：前接口提取变量，后接口用 ${变量名} 引用。

对应函数方法：
extract(name, jsonpath, result) - 从响应里用jsonpath提取变量存入上下文
resolve(template)               - 把字符串里的 ${变量名} 替换为变量值
clear()                         - 清空所有变量


## 通用执行器 (executor.py - ApiExecutor) 【新增】
读取Excel用例后自动执行任意接口，新增接口测试无需写Python代码。
把 ExcelReader、HTTPClient、AssertEngine、ConcurrentRunner、ResultWriter、TestContext 串成完整流程。
链路用例（含"提取"列或入参含 ${）自动走串行，普通用例并发。

对应函数方法：
ApiExecutor(http_client, max_workers=5) - 实例化（http_client用conftest的admin_client）
run(file_name, timeout=60) - 执行一个Excel用例文件，自动并发/串行/断言/回写
